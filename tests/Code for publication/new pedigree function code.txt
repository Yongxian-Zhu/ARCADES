What changes is the absolute uncertainty scale.

Interpretation

If you don't have justification for the 95% interpretation, then removing 1.96 may actually be more honest.

Because currently your code is implicitly saying:

“These pedigree relative ranges are 95% half-widths of an approximately Normal uncertainty distribution.”

If that assumption is not valid, then dividing by 1.96 may artificially make the model too confident.

Without 1.96, you're effectively treating the pedigree range as already being on the sigma scale.

Practical effect on the Bayesian model

Larger sigmas mean:

weaker observation likelihoods
wider posteriors
mass-balance constraints have relatively more influence
reconciliation will be driven more by network structure than by observed values

So removing 1.96 makes the model more conservative.

Best practice

K_95 = 1.96   # set to 1.0 if pedigree ranges are already sigma-like


Then use:

r = _relative_half_range(q, dim) / K_95
s = _dim_sigma(q, dim, y) / K_95


That way you can test both assumptions.

Argo: Big picture

This script does four main things:

Defines a small steel flow network with true flows that exactly satisfy mass balance.
Creates noisy observed flows and assigns pedigree scores to each flow.
Computes uncertainty two different ways:
RSS: pedigree dimensions are treated as independent error sources
Independent: pedigree dimensions are treated as independent corroborating measurements
Builds and samples Bayesian MFA models under both assumptions, then compares the posterior results.

I'll go top to bottom and explain what each part does and why.

def compute_sigmas_independent(scores, y):
    """
    Independent-measurement approach: each dimension yields its own sigma.
    Returns dict {dim: sigma_d} plus the effective combined sigma from
    precision-sum:  sigma_eff = 1/sqrt(sum_d 1/sigma_d^2)
    """
    sigmas = {}
    tau_sum = 0.0
    for dim in DIMENSIONS:
        q = _quality_index(scores[dim])
        s = _dim_sigma(q, dim, y)/1.96
        sigmas[dim] = s
        tau_sum += 1.0 / (s ** 2)
    sigmas["effective"] = 1.0 / np.sqrt(tau_sum) if tau_sum > 0 else np.inf
    return sigmas
