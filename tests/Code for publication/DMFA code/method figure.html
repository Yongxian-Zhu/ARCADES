Generic Dynamic Material Flow Analysis (DMFA) Framework

This document presents a modular framework supporting both flow-driven and stock-driven dynamic MFA with integrated Monte Carlo uncertainty propagation. It generalizes prior project-specific implementations [1][2] for reuse across commodities and product systems.

3. Module Reference Table

ModulePurposeKey Equations / Inputs
A. LifetimeProvides survival function S(τ) Normal / Weibull / Lognormal CDF
B. Flow-DrivenCompute stock & scrap from inflow Stock(t)=Σ inflow(i)·S(t−i); generalizes prior code [1][2]
C. Stock-DrivenProject future stock; derive inflow Logistic / Gompertz fit; recursive inflow solution
D. Monte CarloPropagate parameter uncertainty N iterations, percentile summaries
E. AllocationSplit aggregate demand by sub-product alloy_ratio matrix (e.g., 18 alloys [1])

4. Adaptation Checklist for New Commodities

  1. Update lifetime_spec (e.g., consumer durable μ=20 σ=6; electrical μ=50 σ=16; machinery μ=40 σ=13 [2]).
  2. Provide historical demand or stock CSV.
  3. Define sub-product allocation matrix if applicable.
  4. Specify uncertainty distributions per parameter.
  5. Select saturation model for stock-driven mode (logistic/Gompertz).
  6. Run Monte Carlo; validate mass balance; export outputs.
