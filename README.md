# Static and Dynamic Material Flow Analysis

This repository contains an internal Argonne software framework for conducting **static and dynamic material flow analysis (MFA)** of technology, resource, recycling, and circular economy systems.

The tool supports modeling of material stocks, inflows, outflows, losses, recycling, end-of-life flows, and future material demand under user-defined scenarios.

## Purpose

This software is intended to support Argonne research and analysis related to:

- Critical materials and minerals
- Energy technology deployment
- Supply chains and resource demand
- Recycling and circular economy systems
- Manufacturing and industrial systems
- Sustainability and technology assessment

## Main Capabilities

- Static material flow analysis for a reference year or time period
- Dynamic stock and flow modeling over multiple years
- Scenario-based material demand and end-of-life flow estimation
- Recycling, loss, and recovery pathway analysis
- Input/output data processing
- Visualization and reporting of MFA results
